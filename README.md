(덤으로 **단어 시험지 만들기**와 **지문 만들기**도 같이 들어 있습니다)

학원 **운영 시스템**(출결·데일리리포트·월말평가서)과는 **별개의 앱**입니다.
Vercel 프로젝트를 하나 더 만들어 따로 배포하는 게 깔끔합니다.
대신 **Supabase 는 운영 시스템과 같은 것**을 가리킵니다 — 학생 명단을 그대로 쓰려고요.

| | 넣는 것 | 나오는 것 | 필요한 것 |
|---|---|---|---|
| 📝 **단어 시험지** | 단어 목록 붙여넣기 | 시험지(영→한·한→영·섞기) + **정답지**, 여러 벌 순서 다르게 | **아무것도** |
| 📖 **지문 만들기** | 주제·레벨·문법 포인트 | **새 지문** + 단어 + 문제 + 해석 | Claude 키 |
| 📷 **외부지문 스캐너** | 종이 지문 **사진** | 본문 + 문장별 해석 + 단어장 (엑셀로 받기) | Claude 키 · 비밀번호 |
| ✅ **단어 사진 채점** | 학생이 쓴 시험지 **사진** | 문항별 ✅❌❓ · 점수 · 재시 판정 | Claude 키 · Supabase · 비밀번호 |
| 🎙 **목소리 카드 강의** | 내 목소리 **2분** + 대본 | **내 목소리로 읽어 주는** 카드 강의 (판서가 말에 맞춰) | 내 컴퓨터 · Supabase |

## 먼저 알아두실 것 두 가지

**① 아무것도 안 넣고 먼저 써보세요.**
**단어 시험지 만들기**는 키가 없어도, 인터넷이 끊겨도 돕니다 — 전부 브라우저에서 만들거든요.
매일 쓰는 기능이라 일부러 그렇게 뒀습니다. 나머지는 키를 넣으면 하나씩 열립니다.

**② 📷 스캐너와 ✅ 채점은 쓸 때마다 Claude API 요금이 나갑니다.**
사진을 읽는 데 쓰입니다. **단어 시험지 한 장은 몇 원 단위**지만, 반 전체를 날마다 돌리면 쌓입니다.
[console.anthropic.com](https://console.anthropic.com) → **Usage** 에서 보실 수 있으니 처음 며칠은 한 번씩 확인해 보세요.

## 설치 (10분)

**1. 이 저장소를 내 것으로 복사**

위쪽 초록색 **`Use this template`** → **`Create a new repository`**
→ 이름은 아무거나 (예: `class-tools`) → **Create repository**

**2. Vercel 에 올리기**

[vercel.com](https://vercel.com) → **Add New… → Project** → 방금 만든 저장소 **Import**

> ⚠️ **Root Directory 를 `class-tools` 로 바꿔주세요.**
> Framework Preset 은 `Other`. **이것만 틀리면 화면이 안 뜹니다.**

**3. 환경변수 입력** (Import 화면의 Environment Variables)

| 변수 | 값 | 필수 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude API 키 — 스캐너·채점·지문 만들기 | 거의 ✅ |
| `TEACHER_PASS` | **선생님 화면 잠그는 비밀번호.** ⚠️ 안 넣으면 **안 잠깁니다** | ✅ |
| `SUPABASE_URL` | **학원 시스템과 같은 프로젝트**의 주소 (학생 명단을 그대로 씁니다) | 채점·강의 |
| `SUPABASE_SERVICE_KEY` | 같은 화면의 **`service_role`** 키 (anon 아님) | 채점·강의 |
| `RETEST_PERCENT` | 재시 기준 % (기본 15 — 20문항이면 4개부터 재시) | 선택 |
| `ACADEMY_NAME` · `BRAND_COLOR` | 학원 이름 · 대표 색 (예 `#1f7a70`) | 선택 |

`ANTHROPIC_API_KEY` 는 [console.anthropic.com](https://console.anthropic.com) → API Keys 에서 만듭니다.
**학원 시스템에 쓰시던 키를 그대로 넣어도 됩니다.**

**4. Deploy** → 1~2분 뒤 주소가 나옵니다.

**5. 쓰실 기능의 SQL 을 한 번만**

Supabase → **SQL Editor** → 새 쿼리 → 파일을 **통째로** 붙여넣고 **Run**.
「Success. No rows returned」 가 뜨면 된 겁니다.

| 기능 | SQL |
|---|---|
| ✅ 단어 사진 채점 | **`class-tools/sql/vocab.sql`** — 표 2개 + **비공개 사진 저장소** |
| 🎙 목소리 카드 강의 | **`class-tools/sql/lecture.sql`** — 「끝까지 들은 카드」 표 하나 |

## 말로 고치기

클로드 코드를 이 저장소에 연결하면 **말로** 고칠 수 있습니다.

| 이렇게 말하면 | 바뀌는 곳 |
|---|---|
| "지문 말투를 더 쉽게" · "문제를 5개로" | `class-tools/lib/claude.js` 의 `passageGuideline()` |
| "레벨에 고3 추가해줘" | `class-tools/lib/claude.js` 의 `LEVELS` |
| "시험지에 발음기호 칸 넣어줘" | `class-tools/index.html` 의 `시험지()` |
| "한 장에 3단으로 뽑히게" | `class-tools/index.html` 의 `.two` |
| "재시 기준을 20%로" | Vercel 환경변수 `RETEST_PERCENT` (코드 안 고쳐도 됩니다) |
| "이 단원 대본을 카드 5장으로 만들어줘" | `class-tools/voice-lecture/대본/` |

고친 것은 **자동으로 내 주소에 반영됩니다** — `.github/workflows/claude-auto-merge.yml` 이
클로드가 만든 가지를 기본 가지에 합쳐주고, Vercel 이 1~2분 안에 다시 배포합니다.
검토 단계를 되살리고 싶으면 **그 파일을 지우면** 예전처럼 손으로 합치는 방식이 됩니다.
