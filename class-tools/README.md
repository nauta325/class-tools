# 📝 수업 도구 (class-tools)

**단어 시험지 · 지문 만들기 · 외부지문 스캐너 · 단어 사진 채점 · 목소리 카드 강의** — 다섯 가지가 한 앱에.

> Vercel **Root Directory = `class-tools`**

---

## 무엇이 되나

| | 넣는 것 | 나오는 것 | 필요한 것 |
|---|---|---|---|
| 📝 **단어 시험지** | 단어 목록 붙여넣기 | 시험지(영→한·한→영·섞기) + **정답지**, 여러 벌 순서 다르게 | **아무것도** |
| 📖 **지문 만들기** | 주제·레벨·문법 포인트 | **새 지문** + 단어 + 문제 + 해석 | Claude 키 |
| 📷 **외부지문 스캐너** | 종이 지문 **사진** | 본문 + 문장별 해석 + 단어장 (엑셀로 받기) | Claude 키 · 비밀번호 |
| ✅ **단어 사진 채점** | 학생이 쓴 시험지 **사진** | 문항별 ✅❌❓ · 점수 · 재시 판정 | Claude 키 · Supabase · 비밀번호 |
| 🎙 **목소리 카드 강의** | 내 목소리 **2분** + 대본 | **내 목소리로 읽어 주는** 카드 강의 (판서가 말에 맞춰) | 내 컴퓨터 · Supabase |

**셋이 한 줄로 이어집니다** — 지문을 만들거나 스캔하면 그 단어로 **바로 시험지**를 냅니다.

### 왜 「지문 만들기」인가 (가져오기가 아니라)
교재·모의고사 지문을 앱에 올리면 **저작권 문제**가 됩니다.
그래서 **새로 씁니다** — 주제와 레벨만 주면 얼마든지 만들 수 있고, 저작권이 0입니다.
교재를 대신하는 게 아니라 **추가 연습**입니다 (교재는 수업, 이건 복습).

## 설치 (5분)

1. 위쪽 초록 **`Use this template`** → 내 저장소 만들기
2. [vercel.com](https://vercel.com) → **Add New… → Project** → Import
   > ⚠️ **Root Directory 를 `class-tools` 로** 바꿔주세요. Framework 는 `Other`.
3. 환경변수 (전부 **선택**)

| 변수 | 쓰임 |
|---|---|
| `ANTHROPIC_API_KEY` | 지문 만들기 · 스캐너 · 뜻 채우기 |
| `TEACHER_PASS` | **선생님 화면 잠그기** (스캐너·채점·강의 현황). ⚠️ 안 넣으면 **안 잠깁니다** |
| `SUPABASE_URL` | **단어 채점 · 카드 강의**용 — ⚠️ **학원 시스템과 같은 프로젝트**를 가리켜야 합니다 |
| `RETEST_PERCENT` | 재시 기준 % (기본 15 — 20문항이면 4개부터 재시) |
| `SUPABASE_SERVICE_KEY` | 같은 화면의 **service_role** 키 (anon 아님) |
| `ACADEMY_NAME` · `BRAND_COLOR` | 학원 이름·대표 색 |

4. **Deploy** → 주소가 나옵니다.
5. 쓰실 기능의 SQL 을 Supabase → SQL Editor 에 한 번씩 돌리세요.

| 기능 | SQL |
|---|---|
| 단어 사진 채점 | **`sql/vocab.sql`** — 표 2개 + **비공개 사진 저장소** |
| 목소리 카드 강의 | **`sql/lecture.sql`** — 「끝까지 들은 카드」 표 하나 |

> 💡 **아무것도 안 넣고 먼저 써보세요.** 단어 시험지는 키 없이 돕니다.

## 쓰는 법

### 단어 시험지
1. 단어를 붙여넣습니다 — `apple 사과` 한 줄에 하나.
   **탭·쉼표·여러 칸** 다 되고, `1. apple 사과` 처럼 **앞 번호가 붙어 있어도** 알아서 뗍니다.
   엑셀·교재 파일에서 그대로 복사해 오셔도 됩니다.
2. 종류(영→한 / 뜻→영어 / 섞기)·문항 수·**몇 벌**을 고릅니다.
   - **2벌 이상으로 하면 순서가 달라집니다** — 옆자리를 못 봅니다 (A형·B형)
3. **시험지 만들기** → **📥 인쇄 · PDF로 저장**
   - **정답지가 맨 뒤에 같이** 나옵니다. 학생용과 따로 인쇄하세요.

**뜻을 비워두고** 영어만 붙여넣으신 뒤 **「뜻 채우기」** 를 누르면 클로드가 채웁니다
(이미 적으신 뜻은 건드리지 않습니다). ⚠️ **채운 뒤 꼭 한 번 보세요.**

**재시**는 틀린 낱말만 남기고 다시 만드시면 됩니다 — 같은 낱말이어도 **순서가 달라집니다.**

### 지문 만들기
주제·레벨·문법 포인트를 넣고 **지문 만들기**. 20초쯤 걸립니다.
**학생용 한 장**(지문·단어·문제)과 **선생님용 한 장**(정답·해석·뜻)이 따로 나옵니다.

레벨은 학년이 아니라 **낱말 수·문장 길이**로 잡아 둡니다 (`lib/claude.js` 의 `LEVELS`) —
「중2」라고만 하면 매번 길이가 들쭉날쭉해서요.

> ⚠️ **AI 가 쓴 초안입니다. 꼭 한 번 읽어보세요.** 사실이 틀렸거나 우리 반에 안 맞는 문장이 섞일 수 있습니다.

- **학생 글씨를 짐작해서 고치지 마세요.** 고치면 선생님이 아이의 실수를 영영 못 봅니다.

## 📷 외부지문 스캐너

사진을 올리고 **분석**. 30초~1분 걸립니다.

- 사진은 **보내기 전에 브라우저가 줄입니다** (긴 변 1600px). 폰 사진 그대로면 두 장도 안 들어갑니다
- 한 번에 **8장**까지. 넘으면 **누르기 전에** 알려줍니다
- **엑셀로 받기** — 시트 2개(단어·문장)
- **「이 단어로 시험지 만들기」** 로 바로 단어 시험지

> ⚠️ **사진은 분석에만 쓰고 저장하지 않습니다.** 그래도 학생 이름·얼굴이 안 찍히게 찍어주세요.
> ⚠️ **본문이 사진과 같은지 꼭 대조하세요.** 흐린 글자는 `[?]` 로 나옵니다.
> ⚠️ 교재·모의고사 지문을 **학생에게 그대로 배포**하는 건 저작권 문제가 됩니다. 수업 준비용으로만.

## ✅ 단어 시험지 사진 채점

아이는 **종이에 손으로** 쓰고, 선생님이 **폰으로 찍어 올리면** AI가 읽어서 채점합니다.

> 💡 **채점할 때마다 Claude API 가 쓰입니다** (사진을 읽는 데). 쓴 만큼 요금이 나가요 —
> console.anthropic.com 의 Usage 에서 보실 수 있습니다.
> **단어 시험지 한 장은 몇 원 단위**지만 반 전체를 매일 돌리면 쌓입니다. 처음 며칠은 확인해 보세요.

### ① 정답표 — **미리 안 넣어도 됩니다**
처음 채점할 때 한 번만 만듭니다. 세 가지 중 아무거나:

| | |
|---|---|
| **답지 사진** | 답지나 「정답을 다 쓴 시험지」를 찍으면 AI가 읽어 초안을 만듭니다 |
| **엑셀 붙여넣기** | `apple 사과` 한 줄에 하나. 뜻이 여럿이면 쉼표로 |
| **채점하다 이어서** | 정답표가 없으면 채점 화면이 **바로 만들기로 보내줍니다** |

- 교재 표기 `come[be] from` · `judg(e)ment` 는 **그대로** 적으세요 — 둘 다 정답으로 칩니다
- 모아둔 정답표는 **「내 단어장」**(교재·Day별)으로 보입니다

### ② 사진 올려 채점
학생을 고르고 시험지를 찍습니다. 머리글(교재·Day·뜻/스펠)은 **사진에서 읽고**, 못 읽으면 선생님이 고릅니다.

- **인쇄된 낱말로 짝짓습니다** — 순서를 섞은 시험지도 됩니다
- 점수 **`-3/20`**, 다 맞으면 **100**. 20문항 **3개까지 통과, 4개부터 재시**(`RETEST_PERCENT`)
- **스펠 쓰기는 정답표가 꼭 있어야** 합니다 (우리말만 인쇄돼 있어 정답 철자를 알 길이 없습니다)
- 정답표 없이 뜻 쓰기를 채점하면 **「정답표 없이 채점」** 이라고 띄우고 애매한 건 ❓

### ③ 선생님 확인
날짜별 목록 → 열면 **사진 + 문항별 표**(인쇄된 낱말 / 학생 답 / 정답 / ✅❌❓).

- ✅❌❓ 를 눌러 **고치면 점수가 다시** 계산됩니다
- 뜻 쓰기에서 ❌→✅ 로 고치면 **「이 뜻도 맞음」으로 정답표에 더할지** 물어봅니다 → 다음부터 바로 맞음
- **통과 / 재시**로 확정. **오늘 재시 학생만** 모아 보기

### 채점이 지키는 것 ★
| | |
|---|---|
| 학생 글씨 | **쓴 그대로** 읽습니다. 철자를 짐작해 고치지 않아요 — 고치면 아이 실수를 영영 못 봅니다 |
| `[?]` | 못 읽은 글자 → **❓ 선생님 확인**. 틀림으로 밀지 않습니다 |
| 어미 | `조사하다` = `조사한다` = `조사` — 한국어는 어미가 붙습니다 |
| 그래도 다르면 | AI 에게 **「같은 뜻인가」만** 묻습니다. 맞고 틀림은 **우리 규칙**이 정합니다 |
| 하이픈 | `well-known` ≠ `wellknown` — 지우면 틀린 아이가 맞게 됩니다 |
| 사진 | **비공개 저장소**. 볼 때만 10분짜리 주소를 새로 만듭니다 |

## 🎙 목소리 카드 강의

카메라로 찍지 않습니다. **2분 녹음**으로 선생님 목소리를 복제해서,
설명을 읽어 주고 **말에 맞춰 판서가 한 줄씩** 나타나는 강의를 만듭니다.
학생은 `/lecture.html` 에서 카드를 한 장씩 듣습니다.

- 만드는 법은 **[`voice-lecture/README.md`](voice-lecture/README.md)** 에 — 선생님이 하실 일은
  **2분 녹음과 대본 확인뿐**이고, 나머지는 클로드 코드에게 시키시면 됩니다
- **돈이 안 듭니다** (Chatterbox · faster-whisper 둘 다 무료). 내 컴퓨터에서 돕니다
- ★ **마지막 카드까지 들어야** 「✅ 다 들었어요」 — 건너뛴 카드는 안 셉니다
- 선생님은 학생마다 **「몇 장 중 몇 장」** 을 봅니다

> ⚠️ **선생님 목소리만** 쓰세요. ⚠️ 교재 지문·예문을 통째로 읽히지 마세요.
