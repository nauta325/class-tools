# 수업 자료 만들기 — Claude 작업 가이드

단어 시험지 · 지문 만들기 · 외부지문 스캐너 · **단어 사진 채점** · **목소리 카드 강의**.
Vercel **Root Directory = `class-tools`**. 자세한 건 @README.md

## 구조 (단순하게 유지할 것)
- `index.html` — 화면 전부. 빌드 없음
- `api/make.js` — **서버 전부가 이 파일 하나.** 새 기능도 여기에 action 추가
- `lib/claude.js` — 프롬프트 · 레벨 · JSON 정리

## ★ 건드리면 안 되는 것
- **단어 시험지는 서버를 거치지 않습니다.** 전부 브라우저에서 만듭니다 —
  키가 없어도, 인터넷이 끊겨도 나옵니다. **이 성질을 유지하세요.**
  매일 쓰는 기능이라, API 에 묶으면 키 없는 날 수업이 멈춥니다.
- **API 키를 HTML/브라우저로 내보내지 말 것.** 전부 `api/*.js` 에서 `process.env` 로만.
- `normalizePassage()` 의 방어(빈 낱말 버리기·범위 넘는 정답 0으로)를 빼지 말 것 —
  **정답지에 빈칸이 뜨면 선생님이 수업 중에 곤란해집니다.**
- 인쇄 CSS 를 색칠로 바꾸지 말 것. 브라우저는 **배경을 안 찍는 게 기본**이라
  색으로 칠한 칸은 종이에서 사라집니다. **테두리**로 나눠야 합니다.

## ★★ 단어 채점 — **맞고 틀림은 우리 규칙이 정합니다**
AI 에게는 **읽기**(사진)와 **「같은 뜻인가」**만 묻습니다. 「맞았나」를 묻지 마세요 —
같은 답이 날마다 다르게 채점되면 아이가 못 받아들입니다. 규칙은 `lib/vocab.js` 한 곳.

건드리면 안 되는 것
· **학생 글씨를 짐작해서 고치지 말 것.** `읽기지침` 의 그 문장을 약하게 만들면
  선생님이 아이의 실수를 영영 못 봅니다.
· `[?]` 는 **❓(사람 확인)** 입니다. 틀림으로 밀지 마세요.
· 어미 다듬기(`조사하다`=`조사한다`=`조사`)를 빼지 마세요 — 멀쩡한 답이 다 틀립니다.
· 하이픈·따옴표는 **지우지 마세요** (`well-known` ≠ `wellknown`).
· `표기풀기()` — `come[be] from` · `judg(e)ment` 는 둘 다 정답. 교재가 그렇게 적습니다.
· ❓는 **틀린 수에 안 셉니다** (확정 전이라).
· 사진은 **비공개 저장소**에. `public=true` 로 바꾸지 마세요.

## ★ 붙여넣기로 정답표 — 쉼표를 먼저 보지 말 것
「look after 돌보다, 보살피다」 에서 쉼표를 먼저 보면 **「look after 돌보다」가 단어**가 됩니다.
그 쉼표는 **뜻 사이**의 쉼표입니다. 공백으로 쪼개도 안 됩니다 — 구동사가 깨집니다.
순서: **탭·두 칸 → 한글이 처음 나오는 자리 → 쉼표.**

## ★ 목소리 카드 강의 — 판서는 **말에 맞춰** 나타납니다
`lecture-data/<단원>.json` 의 `lines[].at` 이 「이 초에 나타난다」입니다.
말과 글이 어긋나면 아이가 못 따라옵니다 — 줄 순서를 바꾸거나 at 을 지우지 마세요.

· **마지막 카드까지 들어야** 다음이 열립니다. 건너뛰기를 넣지 마세요.
· 끝까지 들은 카드만 기록합니다 (`api/lecture.js` 의 `heard`). 「열어봤다」로 바꾸지 마세요.
· `api/lecture.js` 의 `student_id=eq.<본인>` 을 지우지 마세요 — 남의 진도가 보입니다.
· 강의 내용은 **파일**(lecture-data · lecture-audio), DB 에는 진도만.
  그래야 강의를 고쳐도 아이들 진도가 안 날아갑니다.
· 대본 점검(`voice-lecture/목소리_만들기.py` 의 `대본점검`)을 약하게 만들지 마세요 —
  한 번 돌리면 몇 시간입니다. 번호 하나 틀린 걸 **만들기 전에** 잡는 게 그 함수입니다.
· 무거운 것(torch·chatterbox)은 `만들기()` **안에서** 불러옵니다. 위로 올리면
  `--점검` 이 깔 것 없이 못 돕니다.

## ★ 사진은 저장하지 않습니다
스캐너는 사진을 분석에만 씁니다. 디스크·DB 어디에도 남기지 마세요.
본문은 **사진에 찍힌 그대로** — `scanGuideline()` 의 「지어내지 말 것」을 약하게 만들지 마세요.

## ★ 지문은 「가져오기」가 아니라 「만들기」
교재·모의고사 지문을 넣는 기능을 **추가하지 마세요.** 저작권 문제가 됩니다.
`passageGuideline()` 의 「기존 지문을 베끼지 말 것」 지시를 약하게 만들지 마세요.
