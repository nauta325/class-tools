# 🎙 선생님 목소리 카드 강의

카메라로 찍지 않습니다. **선생님 목소리를 복제한 AI**가 설명을 읽고,
그 말에 맞춰 **판서가 한 줄씩** 나타납니다. 학생은 앱에서 카드를 한 장씩 듣습니다.

> **선생님이 하실 일은 2분 녹음과 대본 확인뿐입니다.**
> 나머지(자르기·설치·만들기)는 **클로드 코드에게 시키세요.** 이 폴더의 명령을 그대로 보여주면 됩니다.

---

## 실제로 이렇게 만들었습니다

| | |
|---|---|
| 녹음 | **2분** — 수업하듯 아무 말이나 |
| 견본 | 그중 **15초** |
| 만든 것 | 31강 · 카드 **144장** · 문장 **742개** · 들으면 약 60분 |
| 걸린 시간 | **이틀** (컴퓨터가 혼자 도는 시간) |
| 돈 | **0원** — Chatterbox(MIT 라이선스)도 faster-whisper 도 무료입니다 |

## 순서

### ① 2분 녹음 → 견본 15초

조용한 곳에서 **수업하듯** 2분쯤 말하고 `.wav` 로 저장하세요
(폰 녹음이면 `ffmpeg -i 녹음.m4a -ar 24000 -ac 1 녹음.wav`).

```bash
python3 목소리견본_자르기.py 녹음.wav
```

조용하고 고르게 말한 **15초짜리 세 개**를 뽑아 줍니다.
**셋 다 들어보시고** 말투가 제일 잘 나온 것을 쓰세요 — 그게 그대로 강의 목소리가 됩니다.
(파이썬에 딸려 오는 것만 써서 **깔 것이 없습니다**)

### ② 대본 · 판서 만들기 — 클로드에게

`대본/u01.json` 이 **예시**입니다. 선생님 단원으로 바꾸시면 됩니다.

```jsonc
{
  "단원": "u01",
  "제목": "현재완료",
  "카드": [{
    "t": "오늘 배울 것",
    "say": ["자, 오늘은 현재완료예요.",          // 한 줄 = 한 조각
            "[[I have finished.]] 처럼요."],      // [[ ]] 안만 영어로 읽습니다
    "screen": [[0, "<b>현재완료</b>  have ＋ p.p."],   // 0 = 첫 번째 say 줄에 나타남
               [1, "지금까지 {{이어지는}} 이야기", "box"]]   // {{ }} 형광펜 · box = 색 상자
  }]
}
```

- **한글은 소리 나는 대로** 적습니다 — `have` → 「해브」, `p.p.` → 「피피」, `is` → 「이즈」
- 카드는 **4~7장**이 적당합니다 (오늘 배울 것 → 언제 쓰나 → 헷갈리는 것 → 정리)
- ⚠️ **교재 지문·예문을 통째로 옮기지 마세요.** 설명 위주로, 예문은 짧게 새로 지으세요

만들고 나면 **깔 것 없이** 먼저 봅니다 — 번호 하나 틀린 걸 모르고 돌리면 몇 시간이 아깝습니다.

```bash
python3 목소리_만들기.py --점검 대본/u01.json
```

### ③ 내 목소리로 읽히기 — 내 컴퓨터에서

한 번만 깔면 됩니다 (**클로드 코드에게 시키세요**):

```bash
python3 -m venv venv && venv/bin/pip install chatterbox-tts faster-whisper
# mac 이면 ffmpeg 도:  brew install ffmpeg
```

```bash
venv/bin/python 목소리_만들기.py 대본/u01.json 녹음_견본1.wav
venv/bin/python 목소리_만들기.py 대본/u01.json 녹음_견본1.wav --카드 3,5   # 그 카드만 다시
```

조각 하나마다 **만들기 → 받아 적어 대본과 비교 → 안 맞으면 다시(최대 3번)** 를 합니다.
AI 목소리는 가끔 딴소리를 하거든요. 그래서 **사람이 다시 들어볼 필요가 거의 없습니다.**

> ★ **시간이 꽤 걸립니다.** 카드 하나가 끝날 때마다 바로 저장하니
> 중간에 멈춰도 같은 명령을 다시 치면 **이어서** 합니다. 틀어 놓고 주무세요.

나오는 것:
```
../lecture-audio/u01/c1.mp3 …      소리 (64kbps 모노)
../lecture-data/u01.json           판서 + 줄마다 나타날 초
../lecture-data/목록.json          단원 목록
```

### ④ 학생이 듣기

배포하신 주소의 **`/lecture.html`** 입니다. 학생번호 + 출결 PIN 으로 들어갑니다.

- 판서가 **말에 맞춰** 한 줄씩 · `{{ }}` 는 형광펜
- 카드가 끝나면 다음 카드로 저절로 · ⏮ ↺ ⏭ · 빠르기 1.0 / 1.2 / 0.9배
- ★ **마지막 카드까지 들어야** 「✅ 강의 다 들었어요」가 나옵니다 (건너뛰기 없음)
- 선생님은 같은 화면의 **「선생님이신가요?」** 로 학생별 **「몇 장 중 몇 장」** 을 봅니다

처음 한 번 Supabase → SQL Editor 에 **`../sql/lecture.sql`** 을 돌려주세요.

## 클로드에게 그대로 복사해 쓰는 말

**대본 만들기**
> 이 단원 설명을 `voice-lecture/대본/u01.json` 형식으로 카드 5장짜리 대본으로 만들어 줘.
> 한글은 소리 나는 대로(have → 해브), 영어는 `[[ ]]` 로 감싸고, 화면 줄은 몇 번째 say 줄에
> 나타날지 번호를 붙여 줘. 강조할 말은 `{{ }}`. 교재 예문은 쓰지 말고 짧게 새로 지어 줘.
> 다 만들면 `python3 목소리_만들기.py --점검` 으로 확인까지 해 줘.

**목소리 만들기**
> `voice-lecture/README.md` 를 보고 필요한 걸 깔아 줘. 그다음 `녹음.wav` 에서 견본을 자르고
> `대본/u01.json` 으로 목소리를 만들어 줘. 오래 걸리면 중간 상황을 알려 줘.

**고치기**
> 2단원 3번 카드만 다시 만들어 줘.
> 판서 글씨가 너무 길어 — 한 줄을 짧게 끊어 줘.
